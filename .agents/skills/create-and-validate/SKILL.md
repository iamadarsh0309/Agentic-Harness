# Create and Validate

Do not duplicate the other skills' instructions — load and follow them by ID.

1. Load the `create-test-program` skill with the `skill` tool and follow its
   workflow to create the example and its exact-output test.
2. When it finishes, load the `validate` skill with the `skill` tool and run
   all of its checks.
3. Summarize both skills' results before proposing any fixes.
